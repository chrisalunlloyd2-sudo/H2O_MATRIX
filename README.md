## 🛠️ TROUBLESHOOTING: "NOT GETTING A RESPONSE"
[timedat: 2026-05-21 14:49:00]

If the chat interface is non-responsive:
1. **Check Thermal Throttling:** If CPU temp > 42°C, the `Thermal Throttling Strategy` pauses the loop.
2. **Check Memory Ceiling:** Ensure system RAM usage is < 400MB. The `llama.cpp` process will be "ditched" if it threatens the 512MB physical limit.
3. **Verify Agent Bridge:** Ensure the background `agent_bridge.py` is running (required for WebView-to-Python communication).
4. **1s Mandate:** If inference takes > 1s, it is automatically terminated. Check `operational_memory` for `[ERROR]` logs.
